1. LLM Cache & Cost Tracking

SQLite (cache.db) keys on hash(model, temp, prompt). On cache hits, returns the response with charged=False while strictly reporting original prompt/completion token counters for valid economic simulations.

2. Checkpoint Tree Sharing

Nodes retain parents and cumulative costs. A child branch inherits the parent prompt and artefacts, evaluating Plan → Code → Fix without duplicate generation of parent context ($C_{\text{shared}} \ll C_{\text{std}}$).

3. Cost-Aware Halving

Calculates empirical stage costs $c_i$. Computes projected remaining expenditure: $\sum_{j > i} c_j \cdot x_j \cdot \text{survivors}$. Picks the largest survivor quota $k_i$ that satisfies budget constraints.
